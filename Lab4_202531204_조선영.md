## 1. Basic Concepts

### Linux
- Linux is an open-source Unix-like operating system.
- It is widely used in servers, cloud computing, embedded systems, and supercomputers.
- Linux has many distributions such as Ubuntu, Fedora, Debian, and CentOS.

### CLI (Command Line Interface)
- CLI is a text-based interface used to interact with a computer by typing commands.
- It can be more efficient and powerful than GUI for many tasks.

### Kernel and Shell
- **Kernel**: The core of the operating system that manages hardware and system resources.
- **Shell**: A program that interprets commands from the user and communicates with the kernel.
- Common shells include **Bash, Zsh, Fish, and Csh**.

## 2. Basic Shell Commands

### `pwd` — Print Working Directory

**Purpose:** Display the current working directory.

```bash
$ pwd
```

**Remember:** `pwd` = "Where am I?"

---

### `cd` — Change Directory

**Purpose:** Change the current working directory.

```bash
$ cd directory_name
```

**Special paths:**
- `/` : Root directory
- `.` : Current directory
- `..` : Parent directory
- `~` : Home directory

**Examples:**

```bash
$ cd /
$ cd ..
$ cd ~
```

**Remember:** `cd` = "Move to another directory"

---

### `ls` — List Directory Contents

**Purpose:** List files and directories.

```bash
$ ls
```

**Options:**
- `-l` : Display detailed information
- `-lh` : Display detailed information with human-readable file sizes

**Examples:**

```bash
$ ls -l
$ ls -lh
```

**Remember:** `ls` = "What is in this directory?"

---

### `clear` — Clear Terminal

**Purpose:** Clear the terminal screen.

```bash
$ clear
```

**Remember:** Use `clear` when the terminal screen becomes cluttered.

---

## 3. Absolute Path vs. Relative Path

### Absolute Path

**Purpose:** Specify the complete path starting from the root directory `/`.

**Example:**

```bash
$ cd /home/user/Documents
```

**Remember:** Absolute path = Full path from `/`

---

### Relative Path

**Purpose:** Specify a path based on the current working directory.

**Example:**

```bash
$ cd ..
```

- `.` : Current directory
- `..` : Parent directory

**Remember:** Relative path = Path from "where I am now"

## 4. File and Directory Commands

**Warning:** These commands may delete or overwrite files and directories. Make sure to back up important contents.

### `cp` — Copy

**Purpose:** Copy files or directories.

```bash
$ cp source destination
```

**Remember:** `cp` = Copy

---

### `mv` — Move

**Purpose:** Move or rename files and directories.

```bash
$ mv source destination
```

**Remember:** `mv` = Move

---

### `rm` — Remove

**Purpose:** Remove files or directories.

```bash
$ rm filename
```

**Warning:** Be careful when using `rm` because it deletes files and directories permanently and irreversibly.

**Remember:** `rm` = Remove

---

### `mkdir` — Make Directory

**Purpose:** Create a new directory.

```bash
$ mkdir directory_name
```

**Remember:** `mkdir` = Make Directory

## 5. Wildcards

**Wildcards** are special characters used to select multiple filenames at once.

### `*` — Matches Any Characters

`*` matches any number of characters.

```bash
$ ls *.txt
```

→ Matches all files ending with `.txt`.

---

### `?` — Matches One Character

`?` matches any single character.

```bash
$ ls file?.txt
```

→ Matches filenames such as `file1.txt` or `fileA.txt`.

---

### `[characters]` — Matches Characters in a Set

`[characters]` matches a character included in the specified set.

```bash
$ ls file[123].txt
```

→ Matches `file1.txt`, `file2.txt`, and `file3.txt`.

**Remember:**
- `*` = Any characters
- `?` = One character
- `[ ]` = One character from a set

## 6. Useful Terminal Tips

### `Tab` — Autocompletion

Press the **Tab key** to automatically complete commands, filenames, or directory names.

**Remember:** `Tab` = Autocomplete

---

### `↑` — Past Commands

Press the **Up Arrow key** to bring back previously used commands.

**Remember:** `↑` = Previous command

---

## 7. Help Commands

### `help`

Use `help` to get information about shell built-in commands.

```bash
$ help
```

**Remember:** `help` = Get help for shell commands

---

### `man`

Use `man` to read the manual page for a command.

```bash
$ man command
```

**Remember:** `man` = Manual

---

## 8. Exiting the Terminal

### `exit`

Use `exit` to exit the terminal.

```bash
$ exit
```

**Remember:** `exit` = Leave the terminal
