## 1. I/O Redirection

I/O Redirection changes where a command receives its input or sends its output.

### Standard Output `>`

By default, standard output is displayed on the screen.  
The `>` operator redirects the output of a command to a file.

```bash
$ ls -lh > file_list.txt
```

The output of `ls -lh` is saved in `file_list.txt`.

**Remember:** `>` = Save output to a file

---

### `cat` — Display File Contents

The `cat` command displays the contents of a text file.

```bash
$ cat file_list.txt
```

**Remember:** `cat` = Show the contents of a text file

---

### Append Output `>>`

The `>>` operator appends output to an existing file.

```bash
$ ls -lh >> file_list.txt
```

If the file already exists, the new output is added to the end of the file.  
If the file does not exist, a new file is created.

**Remember:**
- `>` = Write output to a file
- `>>` = Append output to a file

---

### Standard Input `<`

By default, standard input comes from the keyboard.  
The `<` operator redirects input from a file.

```bash
$ sort < words.txt
```

Input can be redirected from a file and output can also be redirected to another file.

```bash
$ sort < words.txt > sorted_words.txt
```

**Remember:** `<` = Take input from a file

---

## 2. Pipelines `|`

A pipeline sends the output of one command directly to the input of another command.

```bash
$ command1 | command2
```

Multiple commands can also be connected.

```bash
$ command1 | command2 | command3
```

**Examples:**

```bash
$ ls -lh | less
```

```bash
$ ls | wc -l
```

When using `less`, press `q` to exit the screen.

**Remember:** `|` = Output of previous command → Input of next command

---

## 3. Expansion

Special characters can expand their meaning when given to shell commands.

### `echo`

The `echo` command prints text to the terminal.

```bash
$ echo print out the text
```

Output:

```text
print out the text
```

Expansion can also be used with special characters.

```bash
$ echo *
```

`*` expands to filenames in the current directory.

```bash
$ echo ~
```

`~` expands to the home directory of the current user.

**Remember:**
- `echo` = Print text or expanded values
- `*` = Expand filenames
- `~` = Home directory

---

## 4. Backslash `\`

A backslash can be used to ignore a line change when entering a long command.

```bash
$ ls -l \
> -h
```

This allows a long command to be entered across multiple lines.

**Remember:** `\` = Continue a command on the next line

## 5. File Permissions

Linux is a multi-user system.  
Files and directories can have different permissions for:

- **Owner**
- **Group**
- **Others**

The three basic permissions are:

| Permission | Meaning |
|---|---|
| `r` | Read |
| `w` | Write |
| `x` | Execute |

For example:

```text
-rwxrwxrwx
```

The permissions are divided into three groups:

```text
rwx | rwx | rwx
Owner Group Others
```

**Remember:** `r` = Read, `w` = Write, `x` = Execute

---

## 6. `chmod` — Change Permissions

The `chmod` command changes the permissions of a file or directory.

```bash
$ chmod 600 README.md
```

Permission values can be represented using numbers.

| Permission | Binary | Value |
|---|---|---|
| `r` | 100 | 4 |
| `w` | 010 | 2 |
| `x` | 001 | 1 |

Therefore:

```text
rwx = 7
rw- = 6
r-x = 5
r-- = 4
```

### Common Permission Examples

| Value | Permission | Meaning |
|---|---|---|
| `777` | `rwxrwxrwx` | Everyone can read, write, and execute |
| `755` | `rwxr-xr-x` | Owner has full access; others can read and execute |
| `700` | `rwx------` | Only the owner has access |
| `666` | `rw-rw-rw-` | Everyone can read and write |
| `644` | `rw-r--r--` | Owner can read/write; others can only read |
| `600` | `rw-------` | Only the owner can read and write |

**Example:**

To allow the owner to read and write `words.txt`, while the group and others can only read:

```bash
$ chmod 644 words.txt
```

**Remember:** `chmod` = Change file permissions

## 7. Superuser

A **superuser** has system administration authority.  
Some commands require superuser privileges.

### `sudo`

Put `sudo` before a command when superuser privileges are required.

```bash
$ sudo some_command
```

### `sudo -i`

Start a superuser session.

```bash
$ sudo -i
```

### `exit`

Exit the superuser session.

```bash
$ exit
```

**Remember:**
- `sudo` = Run a command with superuser privileges
- `sudo -i` = Start a superuser session
- `exit` = Leave the superuser session

## 9. Shell Script

A shell script is a file containing shell commands that can be executed together.

### Create a Shell Script

```bash
$ nano myscript.sh
```

Example content:

```bash
#!/bin/bash

# This is simply a comment line.

echo "Hello Shell Script!"
```

### Run the Shell Script

```bash
$ sh myscript.sh
```

Output:

```text
Hello Shell Script!
```

If `nano` does not work properly on Windows, the file can be edited using another text editor such as Notepad.

**Remember:** A shell script allows multiple shell commands to be saved and executed from a file.

## 10. `history` — Command History

The `history` command displays previously used commands.

```bash
$ history
```

The command history can also be saved to a text file.

```bash
$ history > history_command.txt
```

**Remember:** `history` = Show previous commands

## 11. `wget` — Download Files

`wget` downloads files from the Internet directly to the current directory.

```bash
$ wget https://example.com/file.jpg
```

**Remember:** `wget` = Download a file from the Internet

---

## 12. `curl` — Transfer Data

`curl` is used for fetching, uploading, and managing data over the Internet.

Basic syntax:

```bash
$ curl [options] [URL]
```

Example:

```bash
$ curl -O https://example.com/file.jpg
```

**Remember:** `curl` = Transfer data over the Internet

---

## 13. `grep` — Search Text

`grep` stands for **Global Regular Expression Print**.  
It is used to search for text within files.

Basic syntax:

```bash
$ grep "search_term" file.txt
```

It searches for the specified text and prints matching lines.

### Common Options

| Option | Purpose |
|---|---|
| `-i` | Case-insensitive search |
| `-v` | Show lines that do not match |
| `-n` | Display matching line numbers |
| `-r` | Search recursively through directories |

**Example:**

```bash
$ echo "This is a test sentence with some words." | grep "test"
```

### Regular Expressions

`grep` supports regular expressions for more complex searches.

| Expression | Meaning |
|---|---|
| `.*` | Match any character zero or more times |
| `\d` | Match a digit (0-9) |
| `[abc]` | Match one character inside the brackets |
| `^` | Match the beginning of a line |
| `$` | Match the end of a line |

**Remember:** `grep` = Find matching text
